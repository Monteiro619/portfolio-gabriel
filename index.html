Câmara 360

Uma interface de consulta a dados legislativos, conectando informações públicas a uma experiência de pesquisa.

Conhecer o projeto
O problema

Consultar diferentes informações sobre a atividade legislativa em uma mesma interface.

A solução

Protótipo com consulta a deputados, órgãos, proposições e eventos, usando a API de Dados Abertos.

O que existe hoje

Projeto independente em HTML, JavaScript, Tailwind CSS e Node.js. O assistente de IA é simulado; informações estimadas devem ser conferidas na fonte oficial.

Emenda

Painel demonstrativo para consultar recursos parlamentares, comparar etapas financeiras e organizar registros.

Conhecer o projeto
O problema

Reunir destinos, valores e etapas de execução em uma visão que facilite o acompanhamento de recursos.

A solução

Filtros por exercício, município e área, gráficos, cadastro e edição de registros, importação e exportação CSV.

O que existe hoje

Demonstração em HTML, CSS e JavaScript, com dados fictícios e armazenamento no navegador de cada visitante. Não se conecta a sistemas oficiais. Os indicadores financeiros não comprovam a entrega do objeto.

Dados oficiais · Acompanhamento legislativo

Radar Legislativo

Pesquisa de proposições e acompanhamento de tramitações, com uma lista pessoal de matérias e anotações.

Conhecer o projeto
O problema

Pesquisar matérias e organizar o acompanhamento de proposições de interesse.

A solução

Consulta à API de Dados Abertos da Câmara com filtros, detalhes da matéria, histórico, prioridades e verificação manual de mudanças.

O que existe hoje

Interface com dados oficiais, exportação CSV e backup. Anotações ficam no navegador e não há notificações em segundo plano. As consultas dependem da disponibilidade da API; é um projeto pessoal, sem ser um serviço oficial da Câmara.

Agenda legislativa · Organização

Agenda da Câmara

Calendário e lista de eventos para consultar pautas e organizar uma agenda pessoal a partir de dados oficiais.

Conhecer o projeto
O problema

Consultar a programação legislativa e reunir os eventos de interesse em uma agenda.

A solução

Calendário, filtros por órgão, assunto e período, detalhes de eventos e pautas, anotações e exportação para arquivo de calendário.

O que existe hoje

Consulta à API oficial da Câmara, agenda salva no navegador, backup e exportação CSV e .ics. Atualizações são verificadas manualmente e arquivos de calendário não sincronizam mudanças automaticamente. É um projeto pessoal de portfólio.
