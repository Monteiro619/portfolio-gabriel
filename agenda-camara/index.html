acompanhar a Câmara.

A Agenda da Câmara conecta informações públicas à organização do trabalho parlamentar. Reúne eventos, órgãos responsáveis, horários e pautas, com uma lista pessoal para acompanhar o que interessa a cada visitante.

Dados e horários

A fonte principal é a API de Dados Abertos da Câmara. A agenda consulta eventos do período selecionado, incluindo os encerrados e cancelados. Horários são apresentados como informados pela fonte, em Brasília.

A API pode registrar eventos conjuntos ou de outros órgãos, como o Congresso Nacional. Os nomes dos responsáveis são mantidos na interface. Pautas e vídeos aparecem quando disponibilizados pela fonte.

Documentação oficial ↗

Filtros e cobertura

Comissões, Plenário e Outros são agrupados pelos órgãos responsáveis. Um evento conjunto pode aparecer em mais de uma categoria. Tipos e situações reproduzem os campos oficiais.

Os filtros atuam sobre os eventos carregados para o intervalo. A lista de órgãos reúne comissões permanentes do catálogo e órgãos presentes no período; não é uma lista de todas as comissões históricas. Consultas aceitam até 93 dias e até 1.000 eventos, com indicação visível caso a coleta fique incompleta.

Se a API falhar, você pode escolher uma cópia oficial coletada do mês, com data visível. Ela não é apresentada como uma consulta atualizada.

Minha agenda e calendário

Os eventos e as anotações ficam no navegador quando o armazenamento local está disponível. Use o backup JSON para transferir a lista. “Verificar atualizações” consulta novamente os eventos salvos e informa diferenças de horário, situação, local ou descrição.

O arquivo .ics pode ser importado em aplicativos de calendário. Ele é uma cópia dos eventos exportados, sem sincronização automática. Conflitos só são sinalizados quando os eventos começam juntos ou quando ambos têm início e fim informados e os intervalos se sobrepõem.

Este é um projeto pessoal de portfólio, não um serviço oficial da Câmara. Confira os eventos e eventuais mudanças na fonte.
